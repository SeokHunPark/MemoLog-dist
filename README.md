# MemoLog 배포 (Android APK)

MemoLog는 순간순간 떠오르는 짧은 생각을 기록하고, 하루·한 주·한 달의 흐름을 AI 요약으로 돌아보는 메모 앱입니다.
이 저장소는 **테스트용 Android APK 배포 전용**입니다(소스 코드는 비공개).

## 다운로드

**항상 최신 버전:** https://github.com/SeokHunPark/MemoLog-dist/releases/latest/download/memolog.apk

지난 버전은 [Releases](https://github.com/SeokHunPark/MemoLog-dist/releases)에서 받을 수 있습니다.

## 설치 방법

1. 안드로이드 폰의 브라우저에서 위 링크를 엽니다.
2. 다운로드한 `memolog.apk`를 엽니다.
3. "출처를 알 수 없는 앱" 설치를 허용하라는 안내가 나오면 허용합니다.
4. 이미 설치돼 있다면 그대로 덮어 설치됩니다(기록은 유지됩니다).

## 업데이트

작은 수정은 앱 안에서 바로 받을 수 있습니다. **설정 → 앱 정보 → 업데이트 확인**을 누르세요.
새 APK가 필요한 큰 변경은 이 페이지에 새 릴리스로 올라옵니다.
